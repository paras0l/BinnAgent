升级词汇相关
1. 进入认识新词后，左边当前任务区为内容展示区，右边改为辅助功能区，放一些按钮或者是介绍，下方固定为操作区不变。
注意内容展示区展示的信息不是固定的
canonical_form	当前学习词汇是什么	必需
entry_type	单词、短语、短语动词还是习语	必需
pronunciation	怎么读、重音和常见发音问题	必需
senses	核心词义，不同词性和用法	必需
examples	在真实语境中如何使用	必需
forms	词形变化如过去式、复数、比较级等形式变化	可选
collocations	经常和哪些词一起出现	可选
common_errors	学习者常犯什么错误	可选
confusions	与近义词、易混词有什么区别	可选
must_remember	本词最值得记住的两三点	可选
内容展示区的右上角增加切换按钮 （精简｜详细）

你需要为此设计一个prompt来向LLM获取这些信息。再辅助功能区增加按钮触发信息补充
