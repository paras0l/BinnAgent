# 16. 阅读导向学习主线

## 1. 产品目标

阅读主线面向已有一定英语基础、认为按教材逐课推进过于重复的学习者。它不是“随机生成一篇文章”，而是用一篇可理解、略有挑战且有信息价值的短文，串起词汇扩充、语法发现、理解纠错、盲点暴露和长期记忆更新。

学习者可在四条主线之间自由切换：

1. 同步教材：按教材单元与课堂节奏推进。
2. 个性化阅读：按兴趣、水平、时间预算和薄弱点生成阅读。
3. 考试备考：按考试目标与题型推进。
4. 通用英语：按真实交流与综合能力推进。

主线是当前默认学习路径，不会删除其他能力或历史记录。

## 2. 每日阅读闭环

```text
画像与近期证据
  -> 选择主题、篇幅和难度
  -> 自主泛读（主旨、态度、推断）
  -> 精读排盲（句子结构、词汇、语法）
  -> 理解纠错与迁移
  -> 写入 Attempt / Memory evidence
  -> 调整下一篇的可理解比例、篇幅和知识焦点
```

生成材料遵循“约 90%-95% 可理解 + 少量新知识”的目标。内容应有事实、观点、冲突或发现，避免只有语言形式、没有阅读价值的练习文章。

## 3. 个性化输入

- 当前 CEFR 水平与目标考试。
- 学习者主动输入的主题和画像兴趣。
- 每日时间预算，用于选择 120-180 或 260-420 词。
- 近期 weak skills、阅读完成记录和理解分数。
- 上一篇记录的生词、语法盲点、纠错说明和主观难度。

教材单元仍可作为上下文来源，但不再是阅读生成的必填依赖。

## 4. 阅读中的体验设计

- 首屏只有一个主动作：生成今天的阅读。
- 学习者可以指定主题；留空时由兴趣与薄弱点自动选择。
- 先读后讲：泛读阶段不提前打断，精读阶段才展开结构和语法。
- 生词不默认全部收藏，必须由学习者确认后进入词汇资产。
- 理解题至少包含一个推断或作者态度问题，避免只做原句定位。
- 复盘记录“哪里理解错了、为什么错、下次如何识别”，而不仅是完成状态。

## 5. Memory 更新边界

阅读完成继续通过 `ExerciseAttemptService` 创建 learner-scoped evidence。证据包含：

- 阅读量、耗时、理解分数和主观难度。
- 访问过的重点句和语法主题。
- 学习者确认的生词、语法盲点与纠错笔记。
- 材料的生成上下文、主题、水平依据和目标词汇。

这些数据用于后续 Recall 与推荐，但生成内容不能绕过确认直接写入词汇、语法掌握度或长期资产。

## 6. 当前实现与后续

当前已完成显式 `learning_track`、主线自由切换、Dashboard 阅读主动作、无教材个性化生成、按时间预算控制篇幅、Prompt v2/eval、阅读证据扩展和本地历史恢复。

后续优先完善：生词逐项确认、理解题交互评分、连续多篇难度校准、兴趣管理、阅读周报，以及基于真实阅读行为的主题多样性控制。
