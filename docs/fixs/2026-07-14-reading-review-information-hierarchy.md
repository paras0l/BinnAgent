# 阅读沉淀复盘缺少重点和层次

## 状态

已修复。

## 问题

原“沉淀复盘”首屏依次展示材料指标、关键词频次、句子难度、结果分布、流程进度、覆盖率、泛读记录和逐句记录。统计型信息占据主要视觉空间，真正帮助学习者复盘的内容——本句结论、关键错误、正确主干、教学步骤、Can-Do 证据和下一步练习——被分散在多个卡片中或压到页面后部。

主要表现：

- 图表与学习结论权重相同，首屏无法快速回答“我哪里错了、下一步练什么”。
- 逐句复盘同时展开原作答、正确拆解、教学步骤和错误标签，信息密度高但缺少阅读顺序。
- 推荐练习使用平铺标签，无法体现优先级。
- NO_ATTEMPT 仍展示“得分 0”，容易把教学路径误解为测评失败。

## 新的信息层级

复盘页改为以下顺序：

1. **本次最重要的收获**：先给出结论、关键卡点和第一优先练习。
2. **逐句精读复盘**：每句先看评估结论、最需要纠正、正确主干和整句含义。
3. **教学步骤**：需要支持时直接展示可执行步骤和一个自检问题。
4. **完整拆解与我的作答**：从句层级、重点短语和原作答按需展开。
5. **泛读理解**：与精读结论分区，保留主旨、态度、段落功能和中心句。
6. **学习过程数据**：关键词、难度、流程和覆盖率降为默认收起的辅助证据。
7. **下一步 / Can-Do / 保存证据**：右侧或页面后部形成明确行动区。

## 关键交互调整

- NO_ATTEMPT 使用“教学复盘”状态，不展示 0 分。
- 错误模式不再显示为无层级标签；首个错误作为“最需要纠正”，并紧邻推荐练习。
- 多个后续练习按 1、2、3 排序展示。
- 掌握度更新使用进度条和前后值；教学线索明确说明没有更新掌握度。
- 原作答、从句层级和短语使用原生 `details` 渐进展开，避免额外 React 状态和重渲染。
- 过程图表统一收进“学习过程数据”，默认不占据复盘首屏。
