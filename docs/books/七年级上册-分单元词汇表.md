## 词汇学习建议

1. **按主题成组学习**：如“个人信息”“家庭活动”“校园地点”“学科评价”“社团能力”“日常作息”“生日庆祝”。
2. **单词和搭配一起记**：例如不只记 `friend`，还要整体运用 `make friends`；不只记 `interested`，还要掌握 `be interested in`。
3. **在句子中掌握词性**：同一个词可能承担不同功能，如 `notice`、`paint`、`sound`、`mark`、`post`。
4. **重视不规则复数**：`goose - geese`、`tooth - teeth`、`grandchild - grandchildren`。
5. **区分近似表达**：`every day` 是时间短语，`everyday` 是形容词；`at the back of` 与 `behind` 均可表达后方，但结构和语境不同。
